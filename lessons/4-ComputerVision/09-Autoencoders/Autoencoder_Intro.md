# 自编码器 (Autoencoder) 入门指南

## 1. 什么是自编码器？

自编码器是一种**无监督学习**神经网络，目标是**学会重建输入数据**。它不需要标签，只从数据本身学习。

```
输入图像 → 编码器 → 潜在向量 → 解码器 → 重建图像
   🖼️    →   📉    →   🎯    →   📈    →    🖼️
```

## 2. 核心思想

自编码器的核心思想是**压缩-重建**：

1. **编码器 (Encoder)**：将高维输入压缩成低维潜在表示
2. **潜在空间 (Latent Space)**：存储数据的精华特征
3. **解码器 (Decoder)**：从潜在表示重建原始输入

```
原始数据 (高维) → 编码器 → 潜在向量 (低维) → 解码器 → 重建数据 (高维)
     784维      →  压缩  →     32维      →  解压  →    784维
```

## 3. 网络结构

```
              输入层              潜在空间              输出层
           ┌─────────┐          ┌───────┐          ┌─────────┐
           │ 28×28   │          │       │          │ 28×28   │
           │  784    │          │       │          │  784    │
           └────┬────┘          └───┬───┘          └────┬────┘
                │                   │                   │
           ┌────┴────┐          ┌───┴───┐          ┌────┴────┐
           │  512    │          │       │          │  512    │
           └────┬────┘          │  32   │          └────┬────┘
                │               │       │               │
           ┌────┴────┐          │ (压缩) │          ┌────┴────┐
           │  128    │          │       │          │  128    │
           └────┬────┘          │       │          └────┬────┘
                │               └───────┘               │
                └──────────────►       ◄───────────────┘
                           编码器    解码器
```

## 4. 简单实现

```python
import torch
import torch.nn as nn

class AutoEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        # 编码器：逐步压缩
        self.encoder = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 32)  # 压缩到32维潜在向量
        )
        
        # 解码器：逐步重建
        self.decoder = nn.Sequential(
            nn.Linear(32, 128),
            nn.ReLU(),
            nn.Linear(128, 784),
            nn.Sigmoid()  # 输出范围 [0, 1]
        )
    
    def forward(self, x):
        z = self.encoder(x)      # 编码
        x_hat = self.decoder(z)  # 解码
        return x_hat
```

## 5. 损失函数

自编码器的目标是让重建输出尽可能接近原始输入：

```python
# 重建损失
loss = nn.MSELoss()(x_hat, x)  # 均方误差
# 或
loss = nn.BCELoss()(x_hat, x)  # 二元交叉熵（像素值在[0,1]时）
```

## 6. 三种主要类型

### 6.1 普通自编码器 (Vanilla Autoencoder)

```
干净输入 ─→ 编码器 ─→ 潜在向量 ─→ 解码器 ─→ 重建输出
```

**用途**：降维、特征提取

### 6.2 去噪自编码器 (Denoising Autoencoder)

```
输入+噪声 ─→ 编码器 ─→ 潜在向量 ─→ 解码器 ─→ 干净输出
   noisy   ─→    学习去除噪声    ─→   clean
```

**训练方式**：
```python
# 添加噪声
noisy_input = clean_input + noise

# 训练目标：从噪声输入重建干净图像
output = model(noisy_input)
loss = criterion(output, clean_input)  # 注意目标是干净图像
```

**用途**：图像去噪、数据清洗

### 6.3 变分自编码器 (Variational Autoencoder, VAE)

```
输入 ─→ 编码器 ─→ 均值 μ ─┐
                └─→ 方差 σ ─┼─→ 采样 z ~ N(μ, σ) ─→ 解码器 ─→ 输出
```

**特点**：
- 学习潜在空间的概率分布
- 可以生成新数据
- 损失函数 = 重建损失 + KL散度

```python
class VAEEncoder(nn.Module):
    def forward(self, x):
        z_mean = self.fc_mean(x)      # 预测均值
        z_log = self.fc_log(x)        # 预测方差的对数
        
        # 重参数化技巧
        eps = torch.randn_like(z_mean)
        z = z_mean + torch.exp(z_log) * eps
        
        return z_mean, z_log, z
```

**用途**：图像生成、数据增强

## 7. 应用场景

| 应用 | 说明 | 类型 |
|-----|------|------|
| **数据压缩** | 将高维数据压缩到低维 | 普通AE |
| **特征提取** | 用潜在向量作为特征 | 普通AE |
| **图像去噪** | 从噪声图像恢复干净图像 | 去噪AE |
| **超分辨率** | 低分辨率→高分辨率 | 普通AE |
| **异常检测** | 重建误差大的样本视为异常 | 普通AE |
| **图像生成** | 从潜在空间采样生成新图像 | VAE |
| **数据增强** | 生成更多训练数据 | VAE |

## 8. 应用示例

### 8.1 图像去噪

```
训练前：添加随机噪声
训练时：输入噪声图像，目标干净图像
训练后：模型学会去除噪声

┌─────────────┐          ┌─────────────┐
│  噪声图像   │   AE     │  干净图像   │
│  ░░█░░█░░  │  ───→   │   ██  ██   │
│  ░█░░░█░░  │          │    █  █    │
└─────────────┘          └─────────────┘
```

### 8.2 超分辨率

```
低分辨率图像   AE     高分辨率图像
  14×14     ───→      28×28
                    ↑
               模型学会填充细节
```

### 8.3 异常检测

```
正常样本重建误差小：  ||x - x̂|| ≈ 0.01
异常样本重建误差大：  ||x - x̂|| ≈ 0.50  ← 检测为异常
```

## 9. 与其他方法对比

### 9.1 与普通神经网络对比

| 方面 | 普通神经网络 | 自编码器 |
|-----|-------------|---------|
| 学习方式 | 监督学习 | 无监督学习 |
| 是否需要标签 | ✅ 需要 | ❌ 不需要 |
| 目标 | 预测标签 | 重建输入 |
| 输出 | 类别/数值 | 与输入相同维度 |

### 9.2 与PCA对比

| 方面 | PCA | 自编码器 |
|-----|-----|---------|
| 类型 | 线性方法 | 非线性方法 |
| 能力 | 线性降维 | 非线性特征学习 |
| 表达能力 | 有限 | 强大 |
| 计算复杂度 | 低 | 高 |

### 9.3 与GAN对比

| 方面 | 自编码器 | GAN |
|-----|---------|-----|
| 结构 | 编码器+解码器 | 生成器+判别器 |
| 生成质量 | 较模糊 | 更清晰 |
| 训练稳定性 | 稳定 | 不稳定 |
| 是否可逆 | ✅ 可编码可解码 | ❌ 只能生成 |

## 10. 训练技巧

### 10.1 潜在向量大小选择

```python
# 太小：信息丢失，重建质量差
latent_dim = 2    # 适合可视化

# 太大：学不到有效特征
latent_dim = 512  # 可能过拟合

# 适中：平衡压缩和重建
latent_dim = 32   # 推荐起点
```

### 10.2 网络深度

```python
# 浅层：简单快速
encoder = [784, 128, 32]

# 深层：更强表达能力
encoder = [784, 512, 256, 128, 32]
```

### 10.3 使用卷积层处理图像

```python
class ConvAutoEncoder(nn.Module):
    def __init__(self):
        super().__init__()
        # 卷积编码器
        self.encoder = nn.Sequential(
            nn.Conv2d(1, 16, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 28→14
            nn.Conv2d(16, 8, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 14→7
        )
        
        # 卷积解码器
        self.decoder = nn.Sequential(
            nn.Upsample(scale_factor=2),  # 7→14
            nn.Conv2d(8, 16, 3, padding=1),
            nn.ReLU(),
            nn.Upsample(scale_factor=2),  # 14→28
            nn.Conv2d(16, 1, 3, padding=1),
            nn.Sigmoid()
        )
```
